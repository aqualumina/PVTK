# PVTK English Translation & OTA Repository

Repository for English translation patches and OTA (Over-The-Air) updates for **PVTK (The World Online)** and **PVTK2**.

## Directory Structure

```text
PVTK/
├── ota/                  # PVTK 1 active OTA files (dict_en.txt, common/, ui/, files.txt, version.txt)
├── update_kit/           # PVTK 1 reusable APK patch kit
└── pvtk2/
    ├── ota/              # PVTK 2 OTA files (dict_en.txt, files.txt, version.txt)
    └── update_kit/       # PVTK 2 reusable APK patch kit
```

## OTA Base URLs

- **PVTK 1:** `https://raw.githubusercontent.com/aqualumina/PVTK/main/ota/`
- **PVTK 2:** `https://raw.githubusercontent.com/aqualumina/PVTK/main/pvtk2/ota/`
